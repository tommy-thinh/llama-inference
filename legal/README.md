Built with Llama. This demo uses Meta Llama 3.2 1B Instruct, locally converted by
bartowski to Q4_K_M GGUF, with the exact artifact pinned in
[`inference/artifacts.lock.json`](../inference/artifacts.lock.json). Model files are not part of this repository.

The complete Llama 3.2 Community License and Acceptable Use Policy are included
here unchanged from Meta's official `meta-llama/llama-models` repository. Pinned
URLs and SHA-256 hashes are recorded in `sources.json`. The Hugging Face upstream
license URL requires gated access; using the official public text mirror does
not grant model access or accept terms. Personally review and accept the model access terms before downloading weights.

The public interface prominently displays **Built with Llama** and links to
`/legal/LLAMA-3.2-LICENSE.txt`, `/legal/LLAMA-3.2-USE-POLICY.md`, and `/legal/NOTICE`.
When distributing copies of model materials, retain the agreement and NOTICE
with those copies. Review the [current official policy](https://www.llama.com/llama3_2/use-policy)
before launch. The included documents explain restrictions, disclaimers, and
the distinction between text-only and multimodal models. This is the text-only
1B Instruct model.
